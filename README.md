# YAMAGUCHI — фен-стайлер 2 в 1

Тестовое задание: адаптивная вёрстка трёх слайдов по макету Figma.

## Стек

- HTML + SCSS + Vanilla JS
- Сборщик: Vite 7
- Анимация и снап по скроллу: GSAP 3 + ScrollTrigger

## Запуск

```bash
npm i           # зависимости
npm run dev     # дев-сервер
```

## Что реализовано

- Три слайда: `fen-styler` (фен и стайлер), `super-light` (суперлёгкий), `section-motor` (мотор BLDC).
- Вёрстка резиновая: десктоп от 1200px, планшет 750–1200px, мобилка до 750px и до 500px.
- Переключение слайдов по скроллу: GSAP ScrollTrigger со снапом — страница доводится до ближайшего слайда, слайд въезжает с анимацией.
- Боковое меню-колесо (только десктоп, от 1200px): иконки на дуге, активный пункт встаёт в центр, колесо проворачивается целиком; клик по пункту прокручивает к слайду.
- Меню во время программной прокрутки не переключается на промежуточные слайды (блокировка синка до остановки скролла).

## Структура

```
src/
  main.js                  точка входа, сборка страницы
  scroll.js                ScrollTrigger: снап и анимация входа слайдов
  main.scss                шрифты, палитра, общие классы (G-container, .icon)
  normalize.scss           сброс стилей
  Components/
    FenStyler/             слайд 1
    SuperLight/            слайд 2
    Motor/                 слайд 3
    FeatureCard/           плашка с иконкой
    menuNavigation/        меню-колесо
public/assets/             шрифты, иконки, картинки
```

## Ассеты

Изображения выгружены из макета в WebP с прозрачностью (качество 90), шрифты — Euclid Circular A и Montserrat, только используемые начертания в woff2 + woff.
